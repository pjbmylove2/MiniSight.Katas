# Katas · 손코딩 실습 코드

일차마다 직접 친 Kata 코드가 쌓이는 곳이다. 설명은 [Study/Book](../Study/Book/00-서문.md)에 있다.

- 폴더: 레벨별 `L0/`(기초), `L1/`(주니어), `L2/`(현장 수학), `L3/`(시니어)
- 파일: 일차 이름 `D001.cs`, `D002.cs` …
- 한 파일 안에 조각마다 `ChunkN()` 메서드, `Run()`이 차례로 부른다
- `Program.cs`의 `Main`은 오늘 일차의 `Run()`만 부른다
- 환경: C# 7.3 / .NET Framework 4.7.2 / Visual Studio 2022
