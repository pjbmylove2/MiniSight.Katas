```markdown
# MiniSight — 멀티 카메라 영상 검사 프레임워크 (C# / .NET Framework 4.7.2 / WinForms / OpenCvSharp)

## 무엇을 하나
카메라(가상 3종)와 폴더 입력에서 영상을 받아 전처리 → 룰 게이지(캘리퍼, PCA 라인, 블랍) → (가상) AI 추론 →
결과 보고(CSV / TCP PLC / HTTP MES) → 이미지 저장까지, 입력별 파이프라인으로 병렬 처리합니다.

## 설계 하이라이트
- Composition Root + Factory + Adapter: 카메라 벤더 추가 시 코어 수정 0줄 (git diff 증명 링크)
- 입력별 전용 작업자 + SemaphoreSlim 기반 유한 비동기 큐: 프레임 순서 보장, 손실 0, backpressure
- Drain/Cancel 2단계 정지 + 단계별 타임아웃 (ADR 0001)
- Object Pool + ReaderWriterLockSlim copy-on-write로 네이티브 엔진 안전 교체
- WinForms 30fps 입력 / 10fps 표시, lock-free 스로틀, GDI 누수 0
- 원자적 설정 저장(.tmp + Flush(true) + File.Replace + .bak)
- TCP 길이 접두 프레이밍 + 재동기화 + 하트비트 + 재연결
```
