# Part 2 · L2 현장 수학 (M01~M08)

> 목표: 통신·영상·광학·모션에서 쓰는 수학을 **손으로 계산하고, C#으로 옮기고, 현장 숫자로 검산한다.**
> 따로 몰아서 하지 않는다. 짝이 되는 J·S 장의 "수학 노트"에서 넘어와 그 자리에서 한다. 장 하나 = 2일차.

## 수학 장의 형식

1. **왜 이 수학인가** — 현장에서 이 계산을 안 하면 무슨 사고가 나나
2. **손계산** — 종이에 직접 푼다. 예제 3개, 숫자는 현장 규모로
3. **그림으로 이해** — 식을 그림 한 장으로
4. **C# 구현** — 10~30줄 Kata, 손계산 결과와 같은지 확인(출력 비교)
5. **현장 검산** — "이 숫자가 말이 되나?" 감각 기르기(단위, 자릿수)
6. **문제 10개** — 정답은 `<details>`

## 수학을 대하는 태도

- 공식을 외우지 않는다. **단위를 따라가면 식이 보인다.** (mm/px × px = mm, px/s ÷ fps = px/프레임)
- 손계산과 코드 결과가 다르면 둘 중 하나가 틀렸다. 어느 쪽인지 찾는 것까지가 공부다.
- 현장 숫자의 감각: 분해능 10µm/px면 1mm는 100px다. 이 감각이 있어야 "말이 안 되는 숫자"를 바로 알아챈다.
