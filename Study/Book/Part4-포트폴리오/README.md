## 블로그 계획

- 블로그 글은 **명령할 때만** 정리한다. "지금까지 완료된 일차별로 블로그 글 정리해라"라고 하면, 완료된 일차 문서의 "블로그 요약" 절을 바탕으로 글을 만든다.
- 시리즈 이름(예): "무한 학습 지옥 L0 · B01 null과 화살표", "현장 수학 M06 · 카메라 고르는 계산".
- 글마다: 한 줄 요약, 🧒 비유, 핵심 그림, 핵심 코드 1조각, 실험 결과, 현장에서의 의미.
