# Part 3 · L3 시니어 (S01~S20)

> 목표: PLC·시리얼·카메라·모션·비전·산업 도메인·장애 진단·운영·리팩토링을 **혼자 해내고, 남에게 설명하고, 문서로 남긴다.**
> 장비가 없으니 시뮬레이터·가상 포트·가상 축·일부러 만든 장애로 연습한다. 그래서 결과물마다 "어떻게 재현했는지"가 같이 남는다.
> 장 하나 = 3~5일차. ★ 표시는 2027년 2월 말까지 먼저 하는 장이다. 산업은 반도체·디스플레이·2차전지를 균형 있게 다룬다.

## 시니어 졸업 기준

- 처음 보는 장애(데드락·누수·통신 끊김·축 알람 중 하나)를 받고 **재현 → 덤프·로그 분석 → 원인 → 조치 → 보고서**를 1시간 안에 혼자 끝낸다.
- "다른 산업 현장에 다른 카메라·PLC·조명·상위 보고 형식"을 받고 **이식 계획(바꿀 파일, 안 바꿀 파일, 테스트, 롤백)**을 15분 안에 설명한다.
- 가상 검사 셀이 100사이클을 결과 누락·중복 없이 돌고, 장애 주입 후 복구한다.
- CI가 녹색이고, v1.0 릴리스에 설치·롤백 방법이 있다.
- [덕목과 소양](../01-덕목과-소양.md) 표의 모든 줄이 ③이다.

## 경계 (지키는 것)

- 가상 장비는 학습용이다. 실제 안전 기능·비상정지·인터록 검증과 실장비 제어 권한은 현장의 승인 절차를 따른다.
- 사내 프레임워크·사내 AI 엔진·실제 고객 프로토콜은 공개하지 않는다. 공개 저장소에는 일반화한 설계와 MiniSight2 적용 사례만 남긴다.
