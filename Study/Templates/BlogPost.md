## 시리즈 추천 순서 (이직용 포트폴리오로 묶기 좋음)

1. 영상 검사 프로그램의 뼈대: 인터페이스와 Template Method
2. 장비 SDK가 바뀌어도 코어는 그대로: Factory + Adapter
3. Composition Root: new는 한 곳에서만
4. 상태 머신과 Observer로 운전 상태 관리하기
5. lock, Interlocked, volatile 차이를 실험으로 확인하기
6. 프레임을 버리지 않는 Bounded Queue와 Backpressure
7. async/await 함정 5가지 (async void, .Wait(), LongRunning + async)
8. 검사 파이프라인 Stop 순서: Drain과 Cancel의 차이
9. UI 스레드 데드락을 Parallel Stacks로 잡기
10. OpenCV Mat 소유권: 누가 Dispose하나
11. 캘리퍼와 라인 피팅으로 에지 위치 재기
12. Native 핸들을 쓰는 AI 엔진을 Object Pool로 감싸기
13. WinForms 라이브 프리뷰 10fps 제한을 lock 없이 만들기
14. TCP 프레이밍과 재연결, 하트비트
15. 정전에도 안 깨지는 설정 파일 저장
16. 종료 순서와 멱등 Dispose
17. 시니어 관점 코드 위험 분석과 ADR
