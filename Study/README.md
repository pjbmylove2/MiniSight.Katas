# 무한 학습 지옥 · FA 현장 SW 필드엔지니어 개조 프로그램

> **목표:** 이 과정을 끝까지 손으로 통과해서 반도체·디스플레이·2차전지 어느 FA 장비 현장에서도 바로 대응하는 필드엔지니어가 된다.
> **환경:** C# 7.3 · .NET Framework 4.7.2 · WinForms · x64 · Visual Studio 2022
> **규칙:** 모든 일차에 손코딩. 출력은 글자 단위로 일치, 핵심 기능 빈칸을 채워 다시 실행, 이유까지 말하기. 틀린 것은 지옥 대기열로 돌아온다.
> 2026-11-19 처음부터 다시 시작했다.
