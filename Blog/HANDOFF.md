# K-프로그래밍 글공방 — 작업 인계 (Codex용)

마지막 작업: 2026-11-03 (Claude Code). 이 문서만 읽고 이어서 작업할 수 있게 적었다.

## 1. 이게 뭔가

티스토리 블로그(k-program.tistory.com, HTML 모드 전용)에 글을 올리는 도우미 웹 페이지 1개.
예전 이름 "MiniSight 블로그 복사대" → **"K-프로그래밍 글공방"** 으로 바꾸고 기능을 넓혔다.

- 공부 글(B01~B14, 끝낸 Day)을 골라 제목·태그·HTML 본문을 복사한다 (예전 기능 그대로).
- **새 글**: 공부 메모를 넣고 AI로 초안을 만들고 다듬은 뒤, 같은 틀(VS2022 다크 코드 상자, 둥근 표 등)의 HTML로 복사한다.
- 제목·태그를 직접 고치거나 AI 추천을 받는다.
- 티스토리 HTML 모드에만 쓴다. 네이버 등 다른 편집기는 지원하지 않는다 (예전에 해 봤다가 뺐다).

## 2. 파일

| 파일 | 역할 |
|---|---|
| `Blog/build-blog.js` | `Study/`(공개용으로 가린 복사본)의 공부 글을 읽어 `template.html`의 `/*__POSTS__*/[]` 자리에 JSON으로 넣어 html 1개를 만든다. 이번에 안 고쳤다. |
| `Blog/template.html` | 페이지 전체 (CSS + 화면 + 마크다운→티스토리 HTML 변환 + 새 글 편집 + AI). **이번 작업은 전부 여기.** |
| `Blog/skin/` | 티스토리 스킨 K-docs (별개 작업, 이번에 안 건드림). |

## 3. 빌드·배포 순서

```bash
# 저장소 루트에서. 공부 글이 바뀌었으면 먼저 publish.ps1로 Study 복사본을 갱신한다.
node Blog/build-blog.js <출력경로>/blog-copy.html
```

- `build-blog.js`는 저장소 **밖** `../publish-sanitize.ps1`의 `$forbidden` 정규식을 읽어서, 공개하면 안 되는 이름이 글에 남아 있으면 빌드를 멈춘다. 그 파일이 없는 PC에서는 빌드가 안 된다 (일부러 그렇게 했다).
- 만든 html은 claude.ai 아티팩트(비공개)로 올린다: `https://claude.ai/artifact/KCPQ8EKRpuhWWrRmWcTfjr`. 이건 Claude 쪽 도구로만 올릴 수 있다. Codex에서는 html 파일까지만 만들고, 올리기는 사용자에게(또는 Claude Code에) 맡긴다.
- 아티팩트 선언: `capabilities: {"sample": {}}` (AI 호출 권한). 이걸 빼고 올리면 AI 버튼이 안 된다.
- 내려받기 복사본: 사용자 PC의 `Downloads/K-프로그래밍 글공방.html` (빌드할 때마다 덮어쓴다). 예전 `MiniSight 블로그 복사대.html`은 지워도 된다.

## 4. template.html 구조 (이번에 바뀐 곳)

- 왼쪽 목록 맨 위 **"새 글"** 묶음: `+ 새 글 쓰기` 버튼 + 저장된 초안 목록. 그 아래 공부 글 묶음은 그대로.
- `#draftPanel` (새 글일 때만 보임): 공부 메모 `#notes`, 추가 요청 `#ask`, AI 버튼들, 본문 마크다운 `#body`.
- 제목 `#title`·태그 `#tags`는 `<input>`. 공부 글은 readonly, 새 글은 고칠 수 있다.
- 공부 글 화면의 `이 글 편집하기 (새 글로 복사)` → 그 글로 새 초안을 만든다 (GitHub 코드 링크·시리즈 링크도 같이 복사).
- 초안 데이터: `localStorage['drafts']` = `[{kind:'draft', id:'d...', title, tags[], notes, md, code[], seriesName, seriesLink}]`.
  **이 브라우저에만** 있다. claude.ai 아티팩트와 내려받은 html 파일은 저장소가 서로 다르다.
- "올렸음" 표시: `localStorage['posted']`, 키는 `tistory:<id>` (초안도 같은 방식).
- 삭제는 두 번 눌러야 된다 (아티팩트 안에서는 `confirm()`이 안 뜬다).

### AI (claude.ai `sample` 기능)

- `window.claude.use('sample')`로 얻는다. claude.ai 밖(내려받은 파일)에서는 `null` → AI 버튼만 꺼지고 나머지는 그대로 된다.
- 버튼 3개:
  - **메모로 초안 만들기**: `draftPrompt()` → 스트리밍으로 받으며 제목/태그/본문 칸을 채운다.
  - **본문 다듬기**: `polishPrompt()` (지금 제목·태그·본문 + 참고 메모).
  - **제목·태그 추천**: `metaPrompt()` → `sample.json`, `modelTier:'quick'`.
- AI 답 형식(`WRITER_RULES`에 적음): `제목: ...` / `태그: a, b` / `---` / 본문 마크다운. `parseAi()`가 쓰는 도중에도 읽는다.
- 멈추기(AbortController), 되돌리기(바로 전 AI 실행 전 상태 1단계), 오류 코드별 안내(`aiMessage`).
- 비용: 버튼을 누른 사람의 Claude 사용량을 쓴다. 처음 한 번 허용 창이 뜬다.

## 5. 확인한 것 / 못 한 것

확인함 (로컬 서버 + 브라우저, 2026-11-03):
- 새 글 만들기, 제목·태그·본문 입력 → localStorage 저장, 미리보기에 VS 다크 코드 상자·표 반영.
- 공부 글은 readonly, `이 글 편집하기`로 복사하면 본문·GitHub 링크 상자까지 따라옴.
- 삭제 두 번 누르기.
- claude.ai 밖에서는 AI 버튼이 꺼지고 안내 문구가 나옴.
- `parseAi()` 단위 확인 (정상 형식 / 쓰는 중 / 형식 없음).

**못 함 (다음 작업자가 확인할 것)**:
1. **실제 AI 호출** — claude.ai에서 아티팩트를 열고 "메모로 초안 만들기"를 눌러 허용 창 → 스트리밍 → 결과 형식이 잘 들어오는지. 이건 사용자 브라우저에서만 된다.
2. AI가 만든 글을 **실제 티스토리 HTML 모드에 붙여넣기** (공부 글 쪽도 아직 사용자 확인 전).
3. 넓은 화면 레이아웃은 눈으로 못 봤다 (좁은 폭만 스크린샷 확인).

## 7. 지켜야 할 규칙

- 공개 저장소다. **고객사 이름이 들어간 로컬 경로**, 그리고 가리기 대상 이름(AI SDK·구 프로그램 이름)을 파일에 쓰지 않는다. 빌드가 막아 주는 건 공부 글뿐이고, template.html이나 이 문서는 직접 조심한다.
- 티스토리 붙여넣기 HTML은 CSS 클래스가 버려지므로 **모든 모양을 style 속성으로** 넣는다 (`TS` 객체).
- `fitTables`는 style 글자 뒤에 **덧붙이기만** 한다. `style.setProperty`를 쓰면 색이 rgb()로 바뀌어 스킨의 `[style*="#hex"]` 다크 덮어쓰기가 안 먹는다.
- 코드 색은 VS2022 다크 (`VS` 객체). 스킨(K-docs)도 같은 색을 쓴다.
- 기존 공부 글 복사 기능(B01~, Day)은 바뀌면 안 된다.
- 코드 스타일: 이 파일은 ES5(`var`, `function`)로 쓰여 있다. 한 줄 if에도 `{ }`.
