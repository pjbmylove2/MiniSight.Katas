# K-docs 티스토리 스킨

K-프로그래밍(k-program.tistory.com)용 문서형 스킨이다. 시안 D: A 문서형 스타일 + C 포트폴리오 기능.

- 배치: 왼쪽 카테고리 · 가운데 본문 · 글 화면 오른쪽 목차와 같은 카테고리 글
- 홈: 소개(직무·기술·GitHub), 지금 연재 중(진행 막대), 시리즈 카드 3개, 최근 글
- 테마: 자동(OS 따라감) / 라이트 / 다크(Claude 데스크톱 스타일) 직접 선택, 코드 블록은 VS2022 다크
- 글꼴: 나눔고딕, 코드 나눔고딕코딩

파일 업로드가 막혀 있어서 **스킨 편집 → HTML 편집**에 붙여넣는 방식으로 만들었다.
그래서 index.xml(스킨 옵션)과 별도 스크립트 파일이 없고, 소개 문장 등은 skin.html 안에 글자로 들어 있다.

## 파일

| 파일 | 붙여넣는 곳 |
|---|---|
| `k-docs/skin.html` | HTML 편집 → **HTML** 탭 (스크립트 포함) |
| `k-docs/style.css` | HTML 편집 → **CSS** 탭 |
| `preview.js` | 올리기 전 로컬 미리보기: `node Blog/skin/preview.js <출력 폴더>` |

## 바꾸는 순서

1. **지금 스킨 백업**: 꾸미기 → 스킨 변경 → 지금 스킨을 "스킨 보관함에 저장". 또는 HTML·CSS 탭 내용을 메모장에 복사해 둔다.
2. 꾸미기 → 스킨 편집 → **HTML 편집**
3. **HTML** 탭: 전부 지우고 `skin.html` 내용을 붙여넣는다
4. **CSS** 탭: 전부 지우고 `style.css` 내용을 붙여넣는다
5. **적용**
6. 꾸미기 → 메뉴에서 블로그 메뉴(홈 · 시리즈 · 포트폴리오 · 방명록)를 정한다

## 글자 고치기

skin.html에서 `고칠 곳:` 주석을 찾는다.

- 기본 테마 (`data-default-theme="auto"`)
- 소개: 직무 한 줄, 제목, 소개 문장, 기술(쉼표로 구분), GitHub 주소
- 지금 연재 중: `data-current`(공개한 편 수) / `data-total`(전체 편 수), 제목, 설명, 주소
- 시리즈 카드 3개: 제목, 꼬리표, 설명, 카테고리 주소

## 주의

- 기존 스킨의 옵션(로고, 프로모션 등)은 이 스킨에서 쓰지 않는다.
- 테마 선택은 방문자 브라우저에만 저장된다.
