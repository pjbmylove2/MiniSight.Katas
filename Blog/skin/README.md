# K-docs 티스토리 스킨

K-프로그래밍(k-program.tistory.com)용 문서형 스킨이다. 시안 D: A 문서형 스타일 + C 포트폴리오 기능.

- 배치: 왼쪽 카테고리 · 가운데 본문 · 글 화면 오른쪽 목차와 같은 카테고리 글
- 홈: 소개(직무·기술·GitHub), 지금 연재 중(진행 막대), 시리즈 카드 3개, 최근 글
- 테마: 자동(OS 따라감) / 라이트 / 다크(Claude 데스크톱 스타일) 직접 선택, 코드 블록은 VS2022 다크
- 글꼴: 나눔고딕, 코드 나눔고딕코딩

## 파일

| 파일 | 내용 |
|---|---|
| `k-docs/skin.html` | 화면 구조와 티스토리 치환자 |
| `k-docs/style.css` | 색·배치·본문 모양 |
| `k-docs/index.xml` | 스킨 정보, 기본 설정, 스킨 편집 옵션(소개·연재·시리즈 카드) |
| `k-docs/images/script.js` | 테마 선택, 기술 칩, 진행 막대, 목차, 읽는 시간, 모바일 카테고리 |
| `k-docs.zip` | 위 파일 묶음 |
| `preview.js` | 올리기 전 로컬 미리보기: `node Blog/skin/preview.js <출력 폴더>` |

## 올리는 순서

1. **지금 스킨 백업**: 꾸미기 → 스킨 변경 → 지금 스킨의 "스킨 보관함에 저장" (문제가 생기면 여기서 되돌린다)
2. 꾸미기 → 스킨 변경 → **스킨 등록** → `k-docs` 폴더의 파일(skin.html, style.css, index.xml, images/script.js)을 올리고 저장 → 적용
3. 꾸미기 → 스킨 편집 → 오른쪽 옵션에서 소개 문장, GitHub 주소, 연재 편 수, 시리즈 카드 주소를 고친다
4. 꾸미기 → 메뉴에서 블로그 메뉴(홈 · 시리즈 · 포트폴리오 · 방명록)를 정한다
5. 수익 → 애드센스에서 광고 위치를 다시 확인한다 (목록 위·아래는 스킨의 `revenue_list_upper/lower` 자리)

## 주의

- index.xml을 바꿔서 다시 올리면 스킨 옵션이 초기화된다(티스토리 문서).
- 테마 선택은 방문자 브라우저에만 저장된다.
